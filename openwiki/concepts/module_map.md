# Module Map

This page serves as a central index for all modules documented within the project, categorized by functional area as defined in the master [module book](/module-book/index.html).

## Module Categories

### AI
* [Easy AI](/module-book/data/modules.js): Connect to LLM providers without the SDK setup boilerplate.

### Files & Data
* [Easy File Manager](/module-book/data/modules.js): Perform file operations without the `os` boilerplate.
* [Easy JSON](/module-book/data/modules.js): Simplified JSON serialization and deserialization.
* [Easy CSV](/module-book/data/modules.js): CSV reading and writing without the csv module boilerplate.
* [Easy Dict](/module-book/data/modules.js): Dictionary operations without the boilerplate.
* [Easy Lists](/module-book/data/modules.js): List helpers that keep your code short and readable.
* [Easy SQL](/module-book/data/modules.js): Open a SQLite connection and run queries/writes without the boilerplate.
* [Easy Archive](/module-book/data/modules.js): Zip and unzip files/folders without the zipfile boilerplate.
* [Easy Config](/module-book/data/modules.js): Config file templates with guiding comments.

### Text & Validation
* [Easy Strings](/module-book/data/modules.js): Utilities for string manipulation and formatting.
* [Easy Text](/module-book/data/modules.js): Text formatting helpers that read like English.
* [Easy Regex](/module-book/data/modules.js): Pull common patterns out of text without writing regex.
* [Easy Validator](/module-book/data/modules.js): Input validation without regex memorization.

### Numbers & Math
* [Easy Numbers](/module-book/data/modules.js): Number checks and calculations without the mental math.
* [Easy Math](/module-book/data/modules.js): Mathematical helper functions and constants for common calculations.
* [Easy Stats](/module-book/data/modules.js): Statistics operations without memorizing the formulas.
* [Easy Converter](/module-book/data/modules.js): Unit conversions without memorizing formulas.

### Time & Control Flow
* [Easy Logging](/module-book/data/modules.js): Start/success/error logging around code blocks and function calls without repeating try/except.
* [Easy Date Formatter](/module-book/data/modules.js): Readable dates without memorizing strftime codes.
* [Easy Flow](/module-book/data/modules.js): Running scripts, timing, and retries without the boilerplate.
* [Easy Async](/module-book/data/modules.js): Run multiple functions at once without touching ThreadPoolExecutor directly.

### Web & Visuals
* [Easy Terminal](/module-book/data/modules.js): Styled terminal output without memorizing Rich markup strings.
* [Easy Web](/module-book/data/modules.js): Web scraping and checks without the requests/BS4 boilerplate.
* [Easy Colors](/module-book/data/modules.js): Hex/RGB/HSL color conversions without memorizing the formulas.
* [Easy Images](/module-book/data/modules.js): Resize, convert, rotate, and inspect images without wrangling Pillow directly.
* [Easy Data Visualization](/module-book/data/modules.js): Auto-picks the right chart type for your data, no matplotlib boilerplate.

### Fun & Generators
* [Easy Game](/module-book/data/modules.js): Pygame setup without the boilerplate.
* [Easy Generator](/module-book/data/modules.js): Passwords, QR codes, UUIDs, and API keys without the boilerplate.
* [Easy Random](/module-book/data/modules.js): Dice, coin flips, and shuffles without wiring up the random module.
